One number, digits only: the honest count of open browser tabs — **137**.

Three browser windows: one full of half-read docs and Stack Overflow answers, one of shopping carts and flight tabs never booked, one of articles saved "for later" since last year. High enough to surprise, odd and specific enough to read as a number somebody actually counted, small enough to stay believable.

## Run it

```sh
python3 main.py
```

Writes `137` (3 bytes, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), then reads the file back and re-validates it against the gate: UTF-8 text of 1 to 5 characters, digits only. Pure Python standard library, deterministic — the same bytes on every run.
